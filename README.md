# Neovim personal configuration

Install [neovim-dotfiles](https://github.com/braintreeps/neovim-dotfiles) first. This scaffold adds personal options, keymaps, and plugins.

Clone this repository into a path that does not already exist:

```sh
git clone https://github.com/cosgroveb/neovim-dotfiles-personal.scaffold.git ~/.config/nvim/lua/personal
nvim
```

Use this repository as a template and substitute your repository URL if you want your own remote. For a nondefault configuration, clone into its `lua/personal` directory.

The examples in this repository are comments. Uncomment an example to use it.
